# Q Department's Unity Audio Playground

Test Project for comparing audio plugins and approaches.

## Spatializer Plugins
- Apple PHASE (source/listener package)
- Meta/Occulus Spatializer (plugin)
- Resonance Spatializer (plugin) [deprecated 2022]
- Steam Audio
- Native Unity Spatializer (plugin)
